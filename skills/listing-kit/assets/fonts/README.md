# Bundled font

`Inter.ttf` is `InterVariable.ttf` from the official Inter 4.1 release
(https://github.com/rsms/inter/releases/tag/v4.1), unmodified.

- sha256: `4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf`
- Licence: SIL Open Font License 1.1, in `OFL.txt` (the release's `LICENSE.txt`).

It is the default and last-resort font for composed screenshots. Apps normally
name their own font files in `.listing-kit/listing.json`.
