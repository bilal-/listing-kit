# Running the skill in an agent

Use the agent to read the project, edit text and run the bundled launcher. Capture calls the device SDK. Compose drives its own headless browser.

| Task | Claude Code | Codex | Copilot CLI | Gemini CLI |
| --- | --- | --- | --- | --- |
| Read and search | Read, Glob, Grep | Shell with cat or rg | Shell | read_file, glob |
| Edit files | Write, Edit | apply_patch | Shell | write_file, replace |
| Run the launcher | Bash | Shell | Shell | run_shell_command |

| Task | Antigravity | Cursor | Kiro | OpenCode |
| --- | --- | --- | --- | --- |
| Read, edit and run commands | Use the agent's file and shell tools | Use the agent's file and shell tools | Use the agent's file and shell tools | Use the agent's file and shell tools |
